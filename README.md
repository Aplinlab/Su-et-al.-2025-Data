# File Directory

Files/folders of particular interest include:

* `/src/0_spike_extraction.ipynb` and `/src/1_statistics_visualisation.ipynb` -
Front-end for all data processing and analysis performed in *Python*. Check
these files and the functions they call from `/src/hff_analysis/` if you are
interested in post-experimental methodological details.
* `/misc/hff_stats.Rmd` - Code for all statistical analysis in *R*. Check this
file if you are interested in the statistical tests used.
* `/src/outputs/JSON/spikes/` - Experimental data in the form of extracted
spike data. Neither the raw recording files nor post-processing per-epoch
traces could be uploaded due to size restrictions, but they can be made
available on individual request.
* `/misc/nerve length measurements.csv` - Length measurements of various leg
and foot features made in SD and Lewis rats. Used to estimate recording
distance for experimental data. Also available in `.XLSX` format in the same
directory.
* `/misc/comsol_efield_model.mph` - Code for the extracellular electric field
model. The code used for the MRG axonal dynamic model has been published under
*Modulating individual axons and axonal populations in the peripheral nerve*
*using transverse intrafascicular multichannel electrodes* (Xie et al., 2023).
* `/src/plot_data/model/` - Model outputs under various conditions. Contains
details on membrane voltage and gating variable changes over time.

A more comprehensive description of this repository can be found below.

## /misc/

* `comsol_efield_model.mph` - Code for the extracellular electric field model.
* `hff_stats.Rmd` - Code for all statistical analysis in *R*. To run this file
yourself, copy the `stats` folder found in `/src/outputs/` into this directory
and rename it to `datafiles`.
* `nerve length measurements.*` - Measurements collected for making recording
distance estimates, included in both `.CSV` and `.XLSX` format. Note that
these files contain some measurements made in Lewis rats which were not
included in the final estimation due to inter-strain differences. These files
were not directly imported for analysis; rather, the relevant data were
transcribed into the `DISTANCE_ESTIMATION_DATA` constant found in
`/src/hff_analysis/constants/experiments.py`.
* `teased_fibre_dissection_platform_v2.5.stl` - Platform used for teased-fibre
procedure. A more hydrophilic printing material can help the lateral channels
to direct blood away from nerve bundles; more hydrophobic materials can result
in globules of blood forming around the bundles, which obstructs vision and is
generally undesirable.

## /src/

* `0_spike_extraction.ipynb` - Front-end pipeline for spike extraction.
**This file will not run without the raw data files**, which could not be
uploaded to this repository due to size restrictions but can be made
available on individual request. However, it contains details of the signal
processing (noise filtration, artefact blanking, epoch separation, etc.) which
was performed, as well as our implementation for the spike extraction itself.
* `1_statistics_visualisation.ipynb` - Front-end pipeline for visualising
data and exporting to *R*. This file will run using the contents of this
repository, and can be run to generate figures used in the paper and data
tables for use in `hff_stats.Rmd` (although its outputs are already included
in this repository).
* `requirements.txt`

### hff_analysis/

Back-end for the analysis. Refer to documentation within or contact us for
more information.

### outputs/

Files generated by various stages of the pipeline, including:

* `images/` - All plots generated during the pipeline. Typically, plots
generated later in the pipeline for use in the paper are located in
`images/figures/`, while other subfolders contain plots generated for
internal data visualisation.
* `JSON/` - Intermediate data files for partially processed data.
    * `file_read_settings/` - Files mostly for internal use which describe how
    each raw recording file was processed. The information of interest here
    can also be found in the equivalent files under `spikes/`.
    * `spikes/` - Experimental data. Stored as per-recording files containing
    extracted spikes, amplitude and latency windows used for extraction, and
    the proportion of epochs which passed our ISI test (no pairs of spikes
    with ISI < 1 ms). Summaries of this data can be easily generated by
    running the first cell of `/src/1_statistics_visualisation.ipynb`.
* `stats/` - Processed data exported to an *R*-compatible format. As mentioned
elsewhere, this folder must be copied into the same directory as
`/misc/hff_stats.Rmd` and renamed to `datafiles` in order to run that file.

### plot_data/

Data from other sources, imported to generate figures. Includes:

* `model/` - Modelling outputs for 7.3-μm and 14-μm diameter fibres. Files
contain data over 3 s, with one value per row and a tick rate of 25 μs. Files
are organised into subfolders by fibre diameter and stimulation frequency, and
use the following naming scheme:
    * `Abeta0` / `Aalpha0` - membrane potential
    * `*_h` - sodium channel inactivation gating variable
    * `*_m` - sodium channel activation gating variable
    * `*_mp` - persistent sodium channel activation gating variable
    * `*_s` - slow potassium gating variable
    * `*_iK` - potassium current
    * `*_iL` - leakage current
    * `*_iNa` - transient sodium current
    * `*_iNap` - persistent sodium current
* `johnson_neyman_output.csv` - Data for generating the Johnson-Neyman plot in
**Figure 3C**, exported from *R*.
* `unit_types.csv` - Datapoints organised by unit type. Used to generate
**Supplementary Figure S2**.
